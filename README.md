# EVChargeIQ ⚡
### AI-Driven EV Charging Analytics and Decision Support System

## 📌 Project Overview

EVChargeIQ is an AI-powered Electric Vehicle (EV) Charging Analytics and Decision Support System designed to analyze EV charging behavior, forecast charging demand, and provide insights for efficient charging station management.

The system uses historical EV charging session data, data preprocessing, exploratory data analysis, and machine learning techniques to understand charging patterns and predict future demand.

## 🎯 Objectives

- Analyze EV charging session patterns.
- Identify peak charging hours and energy consumption trends.
- Forecast future EV charging demand.
- Apply machine learning and deep learning models.
- Provide interactive analytics through a Streamlit dashboard.
- Support data-driven EV charging infrastructure planning.

## ✨ Key Features

- EV charging data preprocessing and cleaning.
- Exploratory Data Analysis (EDA).
- Hourly and daily charging demand analysis.
- Energy consumption analysis.
- Machine Learning-based demand forecasting.
- LSTM-based time-series forecasting.
- Interactive Streamlit dashboard.
- Data visualization and analytical reports.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd EVChargeIQ
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the environment

Windows:

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

## 🚀 Run the Project

Run the Streamlit dashboard using:

```bash

```
